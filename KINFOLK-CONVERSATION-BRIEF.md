# Workforce runtime R&D conversation brief

Agent Control is a provider-neutral runtime for governed jobs, capability-based worker placement, scoped execution, approvals, recovery, verification and retained evidence.

This independent synthetic prototype explores a runtime layer beneath or alongside an existing agentic workforce product. It does not reproduce a product's HR workflows or replace its HR expertise, enterprise integrations or user experience. No endorsement, partnership or integration with Kinfolk is implied.

The working demonstration converts bounded natural-language requests into actual governed jobs. Deterministic specialist workers cooperate through retained plan artifacts. High-risk work pauses for authorized review. An injected wrong-employee action is blocked, its owned process is stopped, its worker is quarantined and the original job continues on an eligible replacement. Actual synthetic state is independently read back.

The experiment compares three worker-availability/approval configurations over the same 120 scenarios. Removing redundancy prevents recovery in the expected failure cases; the failures are retained. These are deterministic-worker results, not evidence of a particular model's HR reasoning quality.

Potential joint R&D topics include approval-contract design, identity/tenant integration, domain adapter scope, independent outcome verification, recovery under enterprise API failures, and frozen workload comparisons across qualified model backends. No integration is promised. Local/API models, real HRIS/payroll connectors, production tenancy, arbitrary hostile-agent isolation and monetary benefit remain unqualified. The Exchange is experimental and not required.
