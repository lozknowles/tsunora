# What is Tsunora?

The operating system for digital work is the product proposition. The initial implementation is a research operating environment, not a general-purpose operating system or evidence of autonomous competence.

Work defines an outcome and bounded requirements. Worker capability and current qualification determine eligibility; execution stays under Agent Control governance. Verification, evidence and accounting complete the contract. Models are resources, not worker identities.

The first workspace supports actual exchange work, workforce, tenders, evidence and internal ledger observations. Existing Jobs, skills, tools, memory, routing and containment remain available through Agent Control. Dedicated Tsunora surfaces for those areas are not yet migrated. No empty Skills or Tools tabs are shown.
