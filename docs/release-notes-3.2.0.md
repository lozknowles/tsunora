# Agent Control 3.2.0

Agent Control 3.2 adds Persistent Teammates: durable named roles that can retain bounded evidence-backed context and routines, delegate through controlled conversations, and coordinate independently verified specialist work.

The five starter profiles are Ask Collingham Engineer, Infrastructure Operator, Independent Auditor, Researcher and Coordinator. Profiles remain provider/model neutral. Their preferred capabilities constrain ordinary Worker Registry placement and do not grant tools, privileges, approvals, leases, ownership or verification authority.

Every specialist assignment and Coordinator synthesis is an ordinary Agent Control Job with its own Run, typed artifact, selected worker, provenance, invocation IDs, normalized token/cost telemetry, verifier result and normal escalation. Production execution requires a registered model-backed Agent Action below the existing HarnessDispatcher, AdaptiveHarness and ToolPolicy boundary. THIN/STANDARD/DEEP routing is unchanged.

The included deterministic demo delegates to Researcher and Independent Auditor, then returns a separately verified Coordinator synthesis across three successful Runs. The demo is non-production and its controlled token/cost figures prove telemetry propagation rather than model quality or external billing.

Commands:

```bash
npm run init:teammates
npm run demo:teammates
npm run check
```

See `docs/persistent-teammates.md` and `docs/evidence/persistent-teammates-3.2.0-verification.md`.
