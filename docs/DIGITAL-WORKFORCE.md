# Digital workforce

**DigitalWorker != Model.**

The inherited exchange worker carries stable identity, organisation, capabilities, tools, permissions, backend revision, model configuration, rate card, concurrency, status and qualification history. Projection adds observed transactions and charges. Backend changes invalidate stale qualifications while retaining identity.

Cross-model memory and skill mechanisms exist elsewhere in Agent Control, but the initial exchange worker does not acquire a universal memory/skill object simply through this product vocabulary. A model is one optional implementation resource. Initial physical fork qualification uses real deterministic Node/Python workers; that is not a new AI-model competence benchmark.
