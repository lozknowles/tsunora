# Digital Labour Exchange v4.15 candidate qualification

Classification: **EXPERIMENTAL, physically qualified only for the bounded deterministic-worker experiment.** This is not a production release or model-provider qualification.

Base: `9ffa265a5` (v4.14.0-rc.2). Additive isolated candidate; package and release versions intentionally remain unchanged. No push, merge, tag, deployment or protected service change was performed.

The final Linux experiment executed 67 process attempts with three independently executing worker implementations across Node.js and Python. Six calibration cases per worker preceded nine held-out cases under five routing policies. All 45 comparisons matched frozen expected outputs. A corrected Windows full comparison also matched all 45; an additional Windows run captured the live authenticated dashboard and actual bidding events. Final source verification: `npm run check`, 2,305 tests passed, zero failures, skipped or cancelled tests.

Frozen workload SHA-256: `b80ad168f3b9a4d0bf0709c798b7c2469c8a3890ee1e016e7444a8dcbbdca8f7`.

All five routing policies cost 108 internal units for nine verified completions. **Economic savings: NOT YET DEMONSTRATED.** Uniform declared tariffs charge 10 micro-GBP per started process and 2 per verifier. These are internal accounting rates, not measured API, electricity or settlement costs. External costs and energy remain unknown; tokens are inapplicable.

A physically terminated owned process incurred a retained charge of 10; another worker completed and verified the work for 12, yielding total completion cost 22. Quarantine excluded the affected worker from later awards. Permission and qualification denials produced zero execution attempts. The existing containment supervisor confirmed process termination and the exchange persisted stopped admission. These controlled faults are not natural reliability or savings observations.

Preserved negative evidence includes initial Windows Unicode extraction failure, a too-late Windows fault injection, and an initial shared-theme regression failure. Subsequent fixes passed their gates. SSH dashboard forwarding was administratively denied; Windows browser evidence does not stand in for remote browser verification. The recording preceded the final qualification-state guard correction; the final Linux execution and full suite tested the sealed code.

Evidence is supplied separately in the task handoff: detailed qualification report, every bid and award, full attempt ledgers and projections, frozen workload, both passed and failed check logs, original WebM, decoded MP4 derivative, video receipt and SHA-256 manifest. Do not interpret these local hashes as externally anchored tamper resistance. No raw operational ledgers are added to the source repository.

The ordinary opt-in server starts an empty exchange. Trusted host registration is required; existing model providers are not automatically onboarded. General coding, open-ended reasoning, LLM quality, autonomous pricing, external settlement, production reconciliation, distributed writers, OS sandbox certification and multi-tenant security remain NOT TESTED or future work. See the design, operations guide and Paperclip review beside this document for interfaces and trust boundaries.

Release authority must review this narrow qualification and integration gaps before any v4.15.0 integration or publication. The concurrent speech candidate is separate and untouched.
