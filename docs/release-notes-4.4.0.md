# Agent Control 4.4.0

Agent Control 4.4 adds governed UX Session Capture and Interactive Replay. A
completed Job Run is projected from existing durable execution history into one
immutable, SHA-256-sealed session identity. Interactive replay, conventional
video, complete transcript, concise digest and evidence manifest derive from
that same record rather than creating a second operational ledger.

The read-only Session Player progressively exposes UX, Agent Control, lane,
baton/gate, tool, sanitised diagnostic and evidence layers. Audience policies
bound every projection. Share capabilities are random, stored only as hashes,
optional-expiry and revocable; they grant no dashboard, shell, mutation or rerun
authority. Reviewer annotations are separate overlays and cannot mutate sealed
evidence.

Normal POE and replay UX names the memory capability **Your Memories**. It can
show relevant memories found, governance/provenance checks, accepted or rejected
memories, human-readable relevance and measured context/token reduction. Memories
remain advisory and cannot override Work Parcels, batons, policy, authoritative
evidence or execution state. The internal architecture remains provider-neutral;
MARM is one optional backend, not Agent Control's memory identity or a mandatory
dependency. Automatic consolidation and idle model swapping are not released.

Physical Chromium qualification replayed the immutable Luna/Qwen/GLM lane run:
Luna and Qwen failed independent gates, GLM passed, aggregation accepted GLM and
Sol was not invoked. Usage reconciled as 10,119 input + 4,778 output = 14,897
total tokens. The same HD recording visibly exercises the Your Memories lifecycle
without exposing backend terminology or memory content. A separate governed A/B
experiment retained 8/8 answers while reducing supplied context from 6,022 to
550 estimated tokens and provider input from 7,844 to 1,608 tokens. Retrieval
latency increased and monetary saving was unavailable, so neither is claimed.
