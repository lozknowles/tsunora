# Agent Control 4.6.1 release verification

This document records the public verification contract for the 4.6.1 security patch. The final release report and GitHub release identify the exact commit, archive SHA-256, schema-v2 receipt digest, external approval digest, complete test total, virgin-install result and 4.6.0 upgrade result.

The mandatory gate covers the complete repository check, focused security regression, typechecking, source distribution, documentation, version consistency, clean installation, supported upgrade, Estate/Process behavior and the retained screenshot set. Every check artifact is content-addressed and bound to the same source commit and digest. The archive is verified independently by the gate.

The release does not claim distinct-principal isolation for shared-token ACP transports, a benchmark winner, whole-node power, exact paid-provider billing or unattended overnight qualification. These are documented capability limitations rather than security-patch release blockers.

Original GLM review packets, raw provider evidence, challenge decisions, accepted findings and remediation evidence are preserved. No paid provider execution is required for this release verification.
