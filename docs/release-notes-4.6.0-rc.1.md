# Agent Control 4.6.0-rc.1 — candidate notes

This is an **unreleased development candidate**. The public stable release remains [4.5.1](https://github.com/lozknowles/agent-control/releases/tag/v4.5.1). See the [current release integration](release-integration-4.6.md) and [versioned Known Limitations](known-limitations-4.6.md) before considering promotion.

## Candidate capabilities

- APK-less Android Standalone: a real Termux-hosted control plane, local dashboard and governed local jobs; no root or remote controller required. Optional Android inference remains unfinished.
- First-run Dashboard, guided Environment Discovery, Estate availability and resource inspection.
- Governed jobs and Process Map with evidence and worker/resource links.
- Model Intelligence and personal benchmark views, with broader showcase qualification still open.
- Usage, token, cache, billing availability and local component energy evidence.
- Existing crew artwork and floating **Mallow**, with new public labels and greetings using that name.

## Public preparation changes

The README and installation journey are qualified from the public repository. Existing-install guidance uses a separate checkout and preserved state. Published 4.5 fixes are carried into the candidate for controller-local worker identity, configuration preservation, recovered discovery state and accurate availability-versus-work presentation.

## Verified subsystem and remaining limits

Usage & Energy remains **PASS WITH LIMITATIONS**, with local physical inference/token accounting and gap-aware component interval integration. Missing billing evidence remains unavailable.

Metered billing, positive cache billing, attributable job/baseline energy, physical tariffs and whole-node electricity remain **BLOCKED_EXTERNAL**. No whole-node or cloud energy claim is made.

The complete target-model showcase still requires genuine benchmark evidence. Overnight-duration qualification and optional Android inference are documented non-blocking limitations for the core release. This documentation checkpoint does not merge, tag, release or deploy the candidate.
