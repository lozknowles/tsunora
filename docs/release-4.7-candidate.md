## Qualification boundaries

The adapter contract and failure controls are exercised by deterministic tests. These are not a live provider or physical microphone qualification. Existing authorised local speech can prove transcription reaches the real runtime; synthetic input must be labelled and cannot substitute for a human Pixel interaction. The active local CPU synthesis route has demonstrated substantial latency.

The final evidence report must record the exact candidate commit, complete test count, browser results, clean-install and previous-release upgrade results. It must retain separate gates for:

- Exact GPT-Live session establishment, speech and final usage using an already-authorised account.
- Physical Pixel speech, playback, microphone denial/recovery, Bluetooth and network transitions.
- A non-trivial voice-originated worker/model execution, naturally justified baton and genuine cache evidence.
- Actual running process/session drill-down, token/cost attribution and readable output/history.
- Genuine end-to-end MP4 with spoken completion and a convenient MSI Downloads copy.

An older recording, a deterministic observation job, a model-family check or an API contract fixture does not close those gates.
