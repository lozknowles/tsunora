# Agent Control 4.0.0-rc.1 release-candidate notes

This is a pushed review candidate, not a formal release. It integrates the 3.9 resilient execution baseline with evidence-driven adaptive orchestration, semantic protected-resource governance and governed Live Shell attachment while retaining the approved Crew/WOPR and Social & Voice/OpenWA interfaces.

The principal behavioral change is continuity across boundaries. An authenticated external request now retains exact initiating text or confirmed voice transcription and safe channel/authentication provenance through its canonical Work Parcel and complete transcript. Route selection, model/account/node transitions, context/token/cost authority, retries, sealed batons, destination continuation, human intervention and independent verification remain separate durable records and stream to the dashboard from the same service projection.

Live Shell observes real owned sessions. It cannot create arbitrary commands, grant tools or widen a contract. Protected-resource Actions are watch-only. A handoff cannot increase authority or remove a parent protected-resource rule. Missing provider telemetry remains unavailable; NVIDIA-hosted models remain partial and routing-disabled.

Candidate acceptance requires the complete deterministic suite plus a natural physical disposable-repository run, at least one qualified social/remote ingress, dashboard/video reconciliation, protected-resource before/after proof, a real supported Live Shell interaction, model-chain accounting and a complete product-generated transcript beginning with the initiating request. Controlled fault injection may prove retry/fallback separately but cannot replace the natural run.
