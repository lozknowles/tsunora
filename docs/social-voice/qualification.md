## C. Social architecture implemented

`SocialChannelProvider` separates authenticated channel ingress, direct identity, health, bounded media and honest delivery receipts from the coordinator. Durable SQLite inbox, stable AC job references, deterministic Work Parcels and runtime request keys prevent duplicate jobs. The existing Work Parcel/runtime owns execution, cancellation and evidence. Exact approved templates remain authoritative; arbitrary social text is not a shell. Operators type `stop AC-3`, not hexadecimal IDs.

## D. OpenWA findings

OpenWA 0.23.4 is a patched private gateway. Real integration exposed three defects: normalized `voice` events were omitted; native `forwardsCount: 0` needed explicit mapping when `isForwarded` was absent; and the old text-size limit truncated audio JSON. All were corrected with regressions. Missing or malformed forwarding provenance remains denied. Ogg/Opus voice-note delivery succeeds where the first WAV attempt failed. Gateway working-tree changes are preserved separately; the gateway is not claimed to be pristine upstream. The current full patch and added forwarding test are retained with the documentation.

## F. Voice architecture implemented

`SpeechProvider` and `SpeechRecognitionProvider` are replaceable authenticated HTTP edges. OmniVoice/Whisper dependencies run separately from Agent Control. Text is retained before optional speech. Voice output is one short outcome sentence, with job numbers spelled as words; logs, durations, URLs and internal IDs stay out of speech. Playback now uses `atempo=0.9`, following the user's clear-but-fast feedback. The final rate adjustment passed real worker generation, Opus decoding and STT checks; a second handset listening confirmation was not requested.

## L. Security findings

Authenticated transport plus enrolled direct identity, freshness, durable dedupe, template grants, rate/active/hourly budgets and bounded audio are enforced. Forwarded/group/unauthorized messages are rejected. Transcription cannot approve consequential work. Social approvals require a separate grant, owned parcel/action snapshot, expiry and one-shot claim; live approval authority remains disabled. Controlled fixtures verified rejection without creating jobs. A compromised gateway remains a trusted-edge risk. No public exposure, arbitrary media URLs, human cloning or secret-bearing recordings were introduced.
