# Agent Control 4.3.0

Agent Control 4.3 integrates Transport Context integrity and Cache-Aware Expert
Delegation into the complete POE/Crew, Live Shell, provider, Work Parcel, token
governor, protected-resource and recovery runtime.

The Warm Cache Runtime dashboard shows real lane timelines, cache observations,
compatibility, candidate route scores, selected Warm Experts, invalidation,
fallback and independent verification. Cache evidence is `AUTHORITATIVE`, qualified
`DERIVED`, or `UNAVAILABLE`; cache warmth never outranks capability, authority,
qualification, health or integrity. Provider cache reads, local reuse, performance
benefit and monetary saving remain distinct claims.

replace keyword-granted authority; unknown effects deny; symlink and prospective
path containment use execution-platform filesystem identity; governed Git disables
hooks/fsmonitor and configuration mutation; and fast execution detects valuable
ignored-state changes. See [runtime safety and route containment](runtime-safety-and-containment.md).
