# Mobile benchmark admission

Historical qualification used external harnesses. Those measurements remain external-harness evidence; their private source snapshots, transport references and admission records are retained with the operator's study.

For the supported candidate runtime path, see [Governed runtime benchmarks](atlas-benchmark-runtime.md). Admission is evaluated by Agent Control using target-adapter observations, preserves unavailable values and refuses at or above 40 degrees Celsius. Service suspension requires explicit authority and restoration evidence.

No private topology or credentials are distributed with this documentation.
