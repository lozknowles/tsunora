# Agent Control 4.7.1 — Usability, Integration & Observability

This patch completes the qualified 4.7 usability and observability update after immutable v4.7.0. The supported core/browser scope retains the known optional voice and physical-device limitations.

- Estate Topology leads to a capability-aware Node Dashboard. Readable resource cards, machine state and bound jobs provide at-a-glance comprehension informed by the useful ToshLLM-style ideas, without copying its implementation or artwork.
- Follow physical nodes to logical jobs, readable Process Map nodes and exact operations in Run Inspector. Connections, selection and mobile controls make the hierarchy easier to follow.
- Inspect input, cached input, fresh input and output tokens per call and whole job; cached input is a subset of input. Cache/reuse and monetary cost remain unknown when no defensible data exists.
- Open prompts, outputs, tools, context and human-readable timestamped history from the dashboard; download canonical Markdown evidence.
- Running sessions retain the pulsing RUNNING lozenge and independently advancing elapsed timer, with reduced-motion support. The accepted Usage recordings pause at least two seconds on each view.
- A shared semantic palette follows system light/dark appearance on desktop and mobile. Live preference changes preserve the session, node and inspector selection. Portrait and landscape touch viewports use the same mechanism.
- Navigation/refresh, native sampling, large-run accounting and governed ownership-return preflight corrections accompany these views. Mallow and the Crew remain available.
