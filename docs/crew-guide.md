# Meet Mallow and the crew

[Installation](installation-first-run.md) · [Actual interface](public-installation-journey.md#j--mallow-and-the-crew)

Mallow is Agent Control's floating guide and chief steward: a way to ask what is happening, inspect evidence and propose governed work. A proposal is not execution permission; review its scope and approve the actual job when appropriate.

[The actual crew view](provenance/EXTERNAL-EVIDENCE.md)

| Character | Established role |
| --- | --- |
| Cadence | Controller and lane dispatcher |
| Quill | Work Parcel reviewer |
| Relay | Tool and execution worker |
| Lumen | Model router and scout |
| Rook | Resource and node guardian |
| Verity | Verification and evidence inspector |

These are the existing product characters, not new generated artwork. Their colour identifies the character; accompanying state text conveys activity. An idle character may move or look around. Animation is presentation, not proof of an executing agent, model call or successful result.

Crew views project recorded work and evidence. Quill's deeper prompt-review instrumentation remains partial. Open the underlying job/resource for the authoritative state.

Public labels and new greetings use **Mallow**. Historical records and compatibility identifiers remain intact. [Implementation-backed crew roles and state semantics](dashboard-characters.md).
