# Public source archive boundary

Public source archives use the committed `.gitattributes` export exclusions. Historical private qualification records and environment-bound research drivers remain unchanged in their original Git revision and private evidence. They are not distributable product defaults. Historical commands requiring those private inputs are absent from the normal npm command list.

The public changelog generalises unnecessary machine names and paths. This is an editorial privacy change, not a new qualification claim. Authoritative original provenance is retained privately in RC1.

Normal source and release packages must contain no runtime state, provider responses, forensic vault, browser profile, credentials, model weights or private qualification directory. Only synthetic test fixtures and explicit public limitations belong in the package. A separate private evidence bundle may contain reviewed, sanitised qualification evidence; its privacy classification must be stated separately. A passing source regex scan is not sufficient publication clearance.

The committed source can still be reviewed in Git. Reproduction of archived physical experiments requires their original environment and private retained evidence; exported source is intended for installing and testing the product.
